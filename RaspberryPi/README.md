## ロータリーエンコーダ配線（EC12E2420801）

### 本基板の接続（パターンカット＋ GPIO 直結）

旧ボリューム用パターン（3.3V 直結など）をカットし、エンコーダを GPIO に直結します。

| Pico | エンコーダ端子 |
|---|---|
| **GP27** | **A** |
| **GP26** | **B** |
| **GND** | **C**（共通） |

```
GP27 ────── A
GP26 ────── B
GND  ────── C
```

- プルアップは Pico の **内部プルアップ**（`INPUT_PULLUP`）を使用
- **3.3V ハーネス線はエンコーダに接続しない**（旧配線のまま B へ繋ぐと短絡の原因になる）

### トラブルシュート

| 症状 | 対処 |
|---|---|
| 回転方向が逆 | `LeftHandDevice.ino` の `ENC_INVERT` を `-1` に変更 |
| クリックごとに方向がおかしい | はんだ付けで A/B が入れ替わっている可能性 → `PIN_ENC_A` と `PIN_ENC_B` を入れ替え |
| 回転でマイコンが落ちる | 3.3V が B 端子に残っていないか確認（パターンカット漏れ） |

## 書き込み手順

1. Arduino IDE を開き、ボードマネージャから `Raspberry Pi Pico/RP2040` をインストールします。
2. ボードを `Raspberry Pi Pico 2 W`（または `Pico W`）に設定します。
3. ルートの `LeftHandDevice.ino` を開き、マイコンへ書き込みます。

## 音量仕様

- 1 クリック（24段）あたり OS 音量 **±2%**
- 接続の有無にかかわらず HID Consumer キーを 1 回送信（Volume Up/Down）

## 実機確認手順

1. エンコーダ未接続で書き込み・起動し、落ちないことを確認
2. 接続後、1 クリックずつ回して音量が ±2% 変化することを確認
3. 高速回転しても USB 切断・再起動が起きないことを確認
